Privacy Policy

Application: NortCoding Media (internal publishing tool for the YouTube channel “Eureka”, @EurekaWhy)
Operator: Edward Martinez · nortcoding.com
Last updated: 19 November 2026

1. What the application does

NortCoding Media is a private tool used only by the channel owner to upload short educational videos to their own YouTube channel and to read public performance statistics of those videos. It has no public users and is not offered to third parties.

2. Data accessed through YouTube API Services

  • Upload (youtube.upload): videos, titles, descriptions and tags created by the owner are uploaded to the owner’s channel after the owner explicitly approves each video.
  • Read (youtube.readonly): public channel and video statistics (views, likes, comments count) of the owner’s own channel.

The application does not access, collect or store data of any other YouTube user.

3. Storage and security

The OAuth refresh token is stored only in the operating system’s secure keychain on the owner’s computer. Statistics are stored in a local database on that same computer. No data is sold, shared with or transferred to third parties.

4. Retention and deletion

Statistics are kept while the channel is active to compare performance. The owner can revoke the application’s access at any time at Google security settings – third-party access; local data is deleted on request or when the tool is retired.

5. Google and YouTube policies

This application uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy.
